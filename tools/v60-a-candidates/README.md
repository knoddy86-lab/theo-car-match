# Letter A

Lindsay picked the slow Emma take (Kokoro-82M `bf_emma`, Apache-2.0, text "A.", speed 0.8, onset cut past the vowel). It is installed as `sounds/letters-emma/let-a.mp3`: −19.2 LUFS integrated, true peak −6.0 dBFS, mono 24 kHz, 48 kbit/s. The other candidate recordings were not kept. There is no separate render script in this repo.
