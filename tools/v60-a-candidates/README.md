# Letter A candidates (v60)

Not used by the game. `sounds/letters-emma/let-a.mp3` is unchanged until a parent picks one of these.

The take in the app was heard as "they". These are other renders of the letter A only. Each file had its onset cut at the vowel so a leading d, th, or n is not left in. All are mono MP3, 24 kHz, 48 kbit/s, about −19.2 LUFS, true peak at or below −4.6 dBFS. Clips shorter than the meter's 400 ms window were measured by repeating the clip (those are marked "repeated").

Checked by placing the file between the Emma clips `let-b.mp3` and `let-c.mp3` (a "B. A. C." carrier) and transcribing with Whisper small.en.

Emma is Kokoro-82M `bf_emma`, Apache-2.0, the same voice as the other 25 Emma letters. Isabella is Kokoro `bf_isabella`, same Apache-2.0 licence. Alba is Piper `en_GB-alba-medium`, CC BY 4.0 (University of Edinburgh CSTR). No Australian voice with a permissive offline licence was available.
